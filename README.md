# 籌碼共振選股系統 (Chip-Resonance Selection System)

> 「籌碼面為主軸、基本面為濾網、產業面為權重、背離訊號為懲罰」的多因子選股模型

## 系統簡介

本系統整合「神秘金字塔」大股東持股週資料、集保中心股權分散表、Goodinfo 董監/質押資料、FinMind 與 TWSE 行情資料等多源資訊，以 9 大因子 + 硬性過濾層組成可量化、可回測驗證的台股選股模型，全程無需人工判斷。

### 三大核心原則

1. **籌碼共振** — 當大戶連續加碼、董監同步進場、散戶退場三者同向時，視為「籌碼集中」訊號。
2. **背離懲罰** — 當股價創新高但大戶退場、或當沖比過熱時，主動扣分，避免追高陷阱。
3. **可驗證** — 所有資料標記 T+3 公布時點，Walk-Forward 滾動驗證，因子 IC 自我淘汰。

## 9 大因子與權重

| 代號 | 因子 | 方向 | 權重 |
|---|---|---|---|
| F1 | 大股東連續加碼 | 加分 | 20% |
| F2 | 產業輪動 | 加分 | 10% |
| F3 | 董監加碼價格落後 | 加分 | 15% |
| F4 | 集中度突破 | 加分 | 10% |
| F5 | 股利穩定 | 加分 | 10% |
| F6 | 散戶退場主力接手 | 加分 | 15% |
| F8 | 回調籌碼守穩 | 加分 | 10% |
| F10 | 利空籌碼修復 | 加分 | 5% |
| F9 | 價籌背離懲罰 | **扣分** | -20% 封頂 |

## 評分公式

Score = Σ wi·zi - Penalty_F9

- zi 為橫截面標準化後的 z-score
- 輸出三層：A 級 (≥75) / B 級 (60-75) / 剔除區 (F9 觸發 ≥2 項)

## 硬性過濾（先排除，不評分）

1. 日均成交量 20 日 < 500 張
2. 董監質押率 > 50%
3. 最近四季累計 EPS < 0
4. 警示股、全額交割股、暫停交易
5. 上市未滿 2 年
6. 股價 < 10 元

## 驗證框架

參考「交易策略回測驗證系統」四個里程碑：
- **M1** — 最小無偏差管線（黃金測試、前視偏差探針）
- **M2** — 統計驗證工具箱（IC/PSR/DSR/CSCV-PBO）
- **M3** — 流程基礎設施（預註冊、可重現性三元組）
- **M4** — 事件驅動覆核（容量曲線、模擬盤）

詳見 `backtest.html`。
