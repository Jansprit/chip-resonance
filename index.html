從神秘金字塔大股東週資料出發，融合基本面、技術面與市場情緒指標

🪙 1. 籌碼共振

當大戶連續加碼、董監同步進場、散戶退場三者同向時，視為「籌碼集中」訊號。大戶用真金白銀投票，是最難造假也最難操縱的領先指標。

⚡ 2. 背離懲罰

當股價創新高但大戶退場、或當沖比過熱時，主動扣分。F9 因子對「價籌背離」最高扣 −20 分，避免追高陷阱。

🔬 3. 可驗證

所有資料標記 T+3 公布時點，Walk-Forward 滾動驗證，因子 IC（Information Coefficient）長期低於 0.02 即降權或移除，具備自我淘汰機制。

🧮 評分合成公式

橫截面標準化（z-score）+ 加權合成，最終對映到 0~100 分

// 每檔股票每週計算一次總分 Score = Σ wi · zi − PenaltyF9 // 其中 zi = 各因子經過橫截面標準化（z-score）後的數值，確保不同量綱可比較 wi = { F1:20, F2:10, F3:15, F4:10, F5:10, F6:15, F8:10, F10:5 } PenaltyF9 = max(0, 20) // 價籌背離懲罰封頂 −20 // 輸出分層 A 級 = Score ≥ 75 → 核心候選，進入買進評估 B 級 = 60 ≤ Score < 75 → 觀察倉，等待因子強化或股價確認 C 級 = 45 ≤ Score < 60 → 中性池 D 級 = Score < 45 → 剔除候選
⚠️ F9 雙重觸發降級規則： 當 F9 觸發條件 ≥2 項（價創 60 日新高但大戶退場 + 當沖比 >40% + 融資使用率 >70% 中任兩項），即使總分落在 A 或 B 級，也必須自動降一級。
