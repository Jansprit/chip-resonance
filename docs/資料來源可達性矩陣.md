## 一、為什麼要有這份文件

本專案最貴的成本從來不是程式碼，而是**「以為某個來源還能用」**：

| 誤判 | 後果 |
|---|---|
| MoneyDJ 免登入可抓 | 寫完解析器才發現要會員 |
| FinMind 是付費牆 | 放棄一個免費、CI 可用的價格來源 |
| 集保 6-1 是股東人數 | 其實是指數清單，F6 因此長期不可用 |
| 玩股網在 CI 可用 | 實際上 datacenter IP 一律 403 |
| MoneyDJ 的 404 是路徑錯 | 實際上是 SSO 登入頁 |

每一個都是「看起來能用，實際上不能」，而且都是寫完程式才發現。
把來源狀態變成**可程式化檢查**，才能讓下一個人（或半年後的我）不必重走一遍。

## 三、踩過的坑（別再踩第二次）

### 玩股網 `before` 參數：規則不透明

頁面 JS 用 `dayjs().startOf("day").valueOf()`（今天 00:00 台北），
但 **2026-10-25 01:30 實測：`before=今天 00:00` 回 HTTP 400**，
往前 1～5 天才會成功（`before=2026-10-24` → 200）。

```python
# 舊（v0.3.1）：固定押一個值 → 2026-10-25 直接整個來源失效
url = f"...?before={_taipei_midnight_ms()}&top=490"

# 新（v0.4.0）：候選清單，依序試到第一個不是 400 的
for before in price_history_before_candidates():   # 今天、昨天、前天…
```

`top` 仍**必須是 490**（30/60/120/240/300/400/491/500/1000 全部 400）。

### FinMind：免費層只有「價格與當沖資料集」

| dataset | 免 token | 備註 |
|---|---|---|
| `TaiwanStockPrice` | ✅ | 回溯 2016-01-04 |
| `TaiwanStockDayTrading` | ✅ | 回溯 2016，但 **`BuyAfterSale` 只會是 `""` 或 `"Y"`，不是當沖量** |
| `TaiwanStockShareholding` | ❌ | 400 `Your level is free` |

→ 個股當沖比（`dt_ratio`）**仍然不可得**。不可用 `""` 當 0% 或 `"Y"` 當 100%
去湊 F9 —— 那是比沒有資料更糟的假訊號。

### 集保 6-1 不是股東人數

`id=6-1` 回 19,998 筆，但內容是**指數成分清單**。
`id=6-3` / `6-4` 是持股**集中度**，也不是股東人數。
個股股東人數目前**沒有任何免費來源** → **F6 維持不可用**。

### 玩股網的 `-data` 籌碼端點需要簽章

`/stock/{id}/...-data` 需要 Cloudflare 的 `x-client-signature`，
純 HTTP 拿不到 → 籌碼資料不在本專案的可用範圍內。

## 五、怎麼自己驗證

```powershell
# 全部來源
python -m backend.scripts.check_sources

# 只查 public（CI 會跑的集合）
python -m backend.scripts.check_sources --public-only

# 同時產生 Markdown 矩陣
python -m backend.scripts.check_sources --matrix docs/source_matrix.generated.md
```

輸出：
- `data/latest/source_health.json` — 機器可讀（CI / 監控用）
- `docs/source_matrix.generated.md` — 人看的即時狀態表

狀態定義（誠實，不美化）：

| 狀態 | 意義 |
|---|---|
| `ok` | 2xx **且**解析出資料 |
| `empty` | 2xx 但沒有資料（等於拿不到東西） |
| `blocked` | 403 / 429 / 被導到登入頁 |
| `error` | 連線失敗或 5xx |

## 六、還沒解決的（誠實清單）

1. **F6 股東人數** — 需要逆向 TDCC 分散表的前端 JS，或走登入路線。
2. **F9 當沖比** — FinMind 免費層不提供當沖量；需找官方或付費替代。
3. **F2 產業籌碼流量** — 需每週保存全市場截面，才能算「大戶淨增持家數」。
4. **F1 / F4** — 需要集保 1-5 的多週歷史，2026-10-24 起每週累積。
5. **MoneyDJ / Goodinfo** — 需要會員或登入 session（本專案不提供破解路徑）。
